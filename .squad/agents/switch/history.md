## Learnings

- Frontend must support VRM swapping, shared animation libraries, and optional character-specific overrides.
- Expression, viseme, and idle animation channels need clean APIs so the backend can drive them predictably.
- Placeholder frontend catalog data should stop at manifest entry points; resolve model, metadata, voice, and override URLs relative to each manifest.
- Avatar viewer work should hang off stable mount point ids and a small runtime bridge. `getAvatarRuntimeMountPoints()` must return stable object identity to avoid remount loops.
- Stage 1 frontend-to-backend bridging overlays backend character summaries onto the local manifest catalog by `character_id`; frontend must degrade cleanly to local-only when backend is unavailable. Route backend bridge calls through a local `/api` Vite proxy.
- Consume `GET /session/speech-lifecycle` as pull-only snapshot after backend-confirmed active-character outcomes. Surface canonical state from the normalized snapshot envelope instead of inventing frontend-specific speech state models.
- 2026-05-15 (humanoid playback tuning): The decisive arm correction was flipping upper-arm `down_up` signs, not adjusting shoulder lift. Leftover `inputOffset: 1` on upper-arm `down_up` can re-lift arms after a sign flip. Live `/display/` is the discriminating check for tuning. Small lower-arm twist is the safe elbow polish path when the generated payload lacks a meaningful elbow-flex channel. When source clips carry lower-arm signal in `forearm.stretch`, derive explicit `elbow.flex` channels on the exporter side. Exporter-composed `lower_arm.rotation` quaternion hints bridge to better web playback before full bone-local export.
- 2026-05-15 (finger/wrist): When payloads show non-trivial spread samples for every digit, the smallest step is root-only finger binding: thumb spread on metacarpal, index/middle/ring/little spread on proximal bones.
- 2026-05-15 (punch tuning): For live punch validation, a dev-only App-level override (`Force gesture.punch.once`) is the narrowest useful seam. Reduce shoulder `front_back` carry, firm hand `down_up`/`in_out`, strengthen punch arm `front_back`. If punch guard stays low, adjust punch-specific upper-arm overrides. If the avatar turns away while per-bone rotations match Unity, treat as root/world transform playback issue.
- 2026-05-17 (App.tsx extraction sequence): Extracted in order: dev-display tooling → character-shell state (`useCharacterShellState.ts`) → speech lifecycle transport (`useSpeechLifecycleState.ts`) → session animation transport (`useSessionAnimationState.ts`) → synthesis playback handoff (`useSpeechPlaybackBridge.ts`) → presentation composition (`surfaceShellPresentation.tsx`) → top-level branch composition → derived shell orchestration (`useSurfaceShellOrchestration.ts`) → runtime-adjacent shell effects (`useAvatarRuntimeShell.ts`) → runtime playback input prep (`useRuntimePlaybackSelection.ts`). App.tsx remains sole `runtime.play(...)` decider and `speech.lifecycle` owner. `frontend-shell-split-surface` must track each new extracted hook as it lands.
